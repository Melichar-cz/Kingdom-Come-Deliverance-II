O hře

Kingdom Come: Deliverance II je historická akční RPG hra od českého studia Warhorse Studios. Hlavním hrdinou je Jindřich ze Skalice. Hra se odehrává v prostředí středověkých Čech a navazuje na události prvního dílu.

Tento web je neoficiální fanouškovský projekt určený pro vzdělávací účely.

Hlavní použité prompty

  1. „Vytvoř školní web o Kingdom Come: Deliverance II v češtině s tmavým středověkým designem a zlatými detaily.“
  2. „Napiš HTML kód hlavní stránky, galerie a stránky o projektu. Všechny stránky propojuj navigačním menu.“
  3. „Vytvoř externí soubor style.css se společným designem pro všechny stránky a přizpůsob ho mobilním zařízením.“
  4. „Vysvětli začátečníkovi, jak vytvořit postupné commity a publikovat web přes GitHub Pages.“

Prompty uprav tak, aby odpovídaly tomu, co jsi při tvorbě skutečně zadal a použil.
